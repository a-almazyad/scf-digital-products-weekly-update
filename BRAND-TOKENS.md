# Manafa presentation theme

This deck follows the visual system used by `a-almazyad/manafa-weekly-cto-update`.

## Identity

- Logo: `assets/manafa-logo.svg`
- Typeface: Alexandria, variable weights 100–900
- Fallback: Segoe UI, Arial, sans-serif

## Core palette

| Role | Token | Hex |
| --- | --- | --- |
| Primary ink / dark surface | `--brand-ink` | `#03020F` |
| Violet accent | `--brand-violet` | `#5337FF` |
| Action blue | `--brand-blue` | `#293BE0` |
| Royal blue | `--brand-royal` | `#0029CC` |
| Supporting light blue | `--brand-light-blue` | `#829DFF` |
| Main light surface | `--surface` | `#F9F9FB` |
| Violet-tinted surface | `--surface-violet` | `#F8F7FD` |
| Blue-tinted surface | `--surface-blue` | `#F3F8FC` |
| Strong neutral rule | `--line-dark` | `#C9CBDF` |
| Muted text | `--muted` | `#717171` |

## Usage rules

- Lead with black and white; use violet and blue selectively.
- Keep panels border-led and mostly shadowless.
- Use 8px radii for controls and 12–16px for grouped panels.
- Use the official Manafa SVG rather than a typed wordmark.
- Avoid gradients; use typography, spacing, contrast and simple linework.
