# SCF Digital Products — HTML presentation

Open `index.html` directly, or serve the folder locally:

```bash
python3 -m http.server 4173
```

Controls:

- Right arrow, Space, Enter, or Page Down: next slide
- Left arrow, Backspace, or Page Up: previous slide
- Home / End: first or last slide
- F: enter or exit full screen

The SCF FinOps screenshot placeholder is on slide 4.

## Theme

The presentation uses the Manafa visual system from the CTO Weekly deck:

- Alexandria typography
- Manafa ink, violet and blue brand tokens
- Official Manafa SVG logo
- Border-led, mostly shadowless layouts

See `BRAND-TOKENS.md` for the complete theme reference.
